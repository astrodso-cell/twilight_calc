# Расчёт сумерек — Android

Приложение для расчёта **восхода, заката, сумерек** и **астрономической ночи**
с учётом фазы Луны, для любой точки и текущей даты.

Алгоритмы — чистые (Без внешних зависимостей):
- **Солнце и сумерки** — NOAA (солнечная геометрия Жана Миуса).
- **Луна** — усечённый ряд Миуса (фаза, высота, восход/заход).
- **«Истинная тёмная ночь»** — астрономическая ночь (Солнце ниже −18°),
  в течение которой Луна находится за горизонтом — лучшие условия для наблюдений.

Времена показываются в локальном часовом поясе устройства.
Геолокация — определение координат по GPS/сети, с ручным вводом как запасным вариантом.

Интерфейс: Material-карточки «Солнце», «Сумерки», «Луна и астрономическая ночь»
в ночной цветовой схеме.

## Сборка APK

Проект полностью стандартный (Gradle + Kotlin + Android Gradle Plugin 8.5.2).
Собрать можно:

1. **Локально** (нужны JDK 17 и Android SDK):
   ```
   ./gradlew assembleDebug
   ```
   APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

2. **Онлайн — GitHub Actions** (без локальной установки SDK) — рекомендуемый способ:
   - закиньте содержимое этой папки в репозиторий GitHub;
   - откройте вкладку **Actions** → рабочий процесс **Build APK** → **Run workflow**
     (или просто сделайте `git push`);
   - после завершения сборки откройте выполненный run и внизу скачайте артефакт
     **`twilight-apk-debug`** — это готовый `app-debug.apk`.

> `local.properties` в репозиторий не попадает (см. `.gitignore`): путь к SDK в CI
> задаётся самим рабочим процессом.

## Команды

| Тип сумерек | Рассвет | Закат |
|---|---|---|
| Гражданские | Солнце 0°..-6° | Солнце 0°..-6° |
| Навигационные | Солнце -6°..-12° | Солнце -6°..-12° |
| Астрономические | Солнце -12°..-18° | Солнце -12°..-18° |

В полярных широтах (полярный день/ночь) некоторые события могут не наступать —
тогда в интерфейсе выводится прочерк «—».
